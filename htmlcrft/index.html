⛏ İLK GÜN

Ağacı yumrukla → Kütük→Kalas→Çalışma Masası → tahta kazma → taş → taş aletler + Fırın → demir → elmas. Gece canavarlar çıkar: kömür+çubuk = Meşale, yün+kalas = Yatak (gece sağ tık = sabah). Aç kalmamak için hayvan avla, fırında pişir. Obsidyen yalnız elmas kazmayla kırılır; TNT'yi çakmak taşıyla ateşle!

🌐 GERÇEK ÇOK OYUNCULU

  1. Aynı bilgisayarda test: Çok Oyunculu → Sunucu Oluştur → tür Yerel. İkinci sekmede bu menüde sunucu listelenir → Katıl. Dünya, bloklar, sandıklar, canlılar ve sohbet gerçekten paylaşılır.
  2. İnternet: Sunucu Oluştur → tür İnternet. Oyunda ESC → Sunucu Paneli → Davet Kodu Üret, kodu arkadaşına gönder.
  3. Arkadaş: Davet Koduna Katıl → yapıştır → Yanıt Kodu Üret → kodu sana geri göndersin → panelde yapıştır → Bağla. Birlikte oynarsınız!
